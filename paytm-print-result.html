Paytm से वापस आ गए हैं

पेमेंट अभी कन्फर्म नहीं बताया जा सकता। अपने Shop QR वाले पेज पर वापस जाएँ। अपना TEST Order ID और निजी Tracking Code डालकर Check Paytm TEST Payment से आधिकारिक Verified Status देखें।

यह केवल Paytm SANDBOX है; असली पैसा नहीं लिया जाता। Paytm की बैंक/सर्वर पुष्टि मिलने पर ही TEST Order Paid दिखेगा। अपने-आप डॉक्यूमेंट Print अभी बंद है।
QR-To-Print Home अगर पेमेंट Pending दिखे, नया पेमेंट शुरू न करें। पहले मौजूदा TEST ट्रांजैक्शन की स्थिति जाँचें। किसी के साथ Tracking Code शेयर न करें।
