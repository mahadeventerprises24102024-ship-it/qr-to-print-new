WINDOWS AUTO-CONNECT • ONE-TIME SETUP

Start Printer Agent automatically after Windows Login

एक बार अपने दुकान के Windows कंप्यूटर में Install करें। अगली बार उसी Windows अकाउंट में Login करते ही Agent खुद शुरू होगा और इंटरनेट उपलब्ध होने पर आपकी दुकान से जुड़ जाएगा। बिना Windows Login किए नहीं चलेगा। Client documents की Automatic Printing अभी OFF है।

Download Windows Agent Installer (GitHub ZIP)
1. Windows PCPrinter का driver और Node.js 20+ install करें। Installer normal Windows account से चलाएँ, Administrator से नहीं।
2. New pairing keyऊपर Generate secure Windows pairing key → Copy pairing key दबाएँ। Key सिर्फ अपने PC पर रखें।
3. One-time installGitHub ZIP Download → Extract All → Install-QR-To-Print-Agent.cmd पर double-click करें। Key Clipboard से सुरक्षित सेव होगी।
4. Test onlineInstall के बाद Refresh status दबाएँ। Windows PC में Login होते ही Agent फिर चालू होगा।

Security: Key Windows user-specific encrypted form में लोकल PC पर रहती है, GitHub/Task arguments में नहीं। दूसरे PC या Windows account पर अलग Setup करें। बंद करने के लिए ZIP में Uninstall-QR-To-Print-Agent.cmd चलाकर यहाँ Revoke connection भी दबाएँ।

Detailed Auto-Start Setup Guide · अगर Windows की सुरक्षा नीति Task Scheduler को रोकती है, तो Agent Install नहीं होगा; PC administrator से अनुमति लें।

Manual browser printing किसी भी compatible local printer पर Windows Agent के बिना भी काम करती है। Agent केवल Printer Discovery/heartbeat और अलग से मंजूर किए गए Canon fixed test के लिए है। ग्राहक की फाइल को Agent ऑटोमैटिक Print नहीं करता।
