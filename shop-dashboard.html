Print one safe test page

This button only requests a fixed QR-To-Print diagnostic page on your Canon G2010. It never prints customer uploads. You must approve each test; limit 5 per hour.

Checking test print availability...

"Submitted" means Windows accepted the test command, not that paper output was confirmed. Customer printing stays disabled.

The key will be hidden after copying or 90 seconds. Regenerating it disconnects an earlier pairing.

1.On your Windows shop PC, install Node.js 20+.
2.Download this project's GitHub ZIP, extract it, then open PowerShell in that folder.
3.Run: node windows-print-agent.js
4.Copy the pairing key before running the agent. The updated agent reads Windows Clipboard automatically; refresh status.

Agent is for Windows only. It requires an internet connection and stays in memory while the terminal remains open. Do not put the secret in GitHub, browser screenshots or PowerShell commands.
