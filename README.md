# QR-To-Print

A fresh starter project for a QR code generator and print platform.

## Current features
- Responsive home page
- QR image generation request and download link
- Starter sections for future print upload and shop dashboard features

## Run locally
Open `index.html` in a modern browser, or serve this folder using any static web server.

## Project structure
- `index.html` — home page and QR generator UI
- `style.css` — responsive styling
- `app.js` — QR form behavior

## Important limitations
This is the first frontend milestone only. It does not yet include file uploads, payments, user accounts, admin authentication, a database, print-job management, or a shop dashboard. Those features need a backend and security review before production use.

The QR image is requested from a third-party service. Do not enter private or sensitive information into the generator.
